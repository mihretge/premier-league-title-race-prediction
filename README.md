# Premier League Title Race Prediction

This project predicts the Premier League title race between Arsenal and Manchester City using a Poisson goal model and Monte Carlo simulation.

## Methods
- Poisson distribution for match outcome probabilities
- Expected points calculation
- Monte Carlo simulation with 10,000 simulations
- Predicted scorelines for each remaining fixture

## Key Results
- Arsenal expected remaining points: 11.89
- Man City expected remaining points: 10.45
- Arsenal predicted final points: 81.89
- Man City predicted final points: 80.45

## Monte Carlo Results
- Arsenal title probability: 59.0%
- Man City title probability: 28.7%
- Tie probability: 12.3%

## Conclusion
The model projects Arsenal as the more likely title winner based on current season scoring patterns.
